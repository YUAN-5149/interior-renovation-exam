3D 工法動畫

術科常考的施工順序，一步一步看構造怎麼疊上去。可以轉角度、看剖面，每一步都附考點。

🪵

高架木地板施工順序

10 步驟・角材骨架、固定筋、夾板、面板

管線 → 基準線 → 四周角材 → PE 布 → 主支架 → 固定筋 → 副支架 → 夾板 → 面板 → 收邊
🧱

石膏板輕隔間施工順序

10 步驟・槽鐵、立柱、開口補強、封板、批土

放樣 → 上下槽鐵 → 立柱 → 開口補強 → 管線 → 單面封板 → 隔音材 → 另一面封板 → 接縫處理 → 收邊
🏠

木作企口天花板施工順序

10 步驟・角材吊筋、格架、起拱、企口板暗釘

放樣 → 周邊角材 → 吊筋 → 骨架 → 校正起拱 → 開口補強 → 鋪企口板 → 接頭錯開 → 收邊 → 表面處理
🔲

輕鋼架天花板施工順序

9 步驟・L 型收邊條、吊筋、主架副架、礦纖板

放樣 → L 型收邊條 → 吊筋 → 主架 → 副架 → 校正水平方正 → 設備開口補強 → 放礦纖板 → 清潔檢查
🚪

造型木作壁板施工順序

11 步驟・機電移位、角材骨架、底板、面材、開孔

放樣 → 機電配合 → 基面檢查 → 立角材 → 線路測試 → 封底板 → 貼面材 → 開孔 → 線板收邊 → 塗裝 → 面板復原與通電測試
🔳

牆面磁磚硬底工法施工順序

11 步驟・純水泥漿、灰誌打底、鋸齒鏝刀、定位片、填縫

基面處理 → 純水泥漿 → 灰誌打底 → 養護 → 分割放樣 → 塗黏著劑 → 由下往上鋪貼 → 清溢漿 → 養護 → 填縫 → 清潔保護
🚿

浴廁壁面防水粉刷施工順序

9 步驟・管線止水、牆角圓角、兩層防水砂漿、彈泥、試水

基面處理 → 管線處理 → 牆角圓角 → 純水泥漿 → 第一層刮毛 → 第二層鏝平 → 彈性防水塗膜 → 養護 → 試水
🪨

牆面抿石子施工順序

10 步驟・塑膠壓條、石粒漿、海綿擦洗、凡立水

基面檢查 → 放樣 → 固定壓條 → 黏結層 → 拌合石粒漿 → 抹平壓實 → 海綿擦洗 → 清洗修整 → 養護 → 凡立水
🧱

牆面文化石軟底施工順序

11 步驟・背面滿抹、先貼轉角石、勾縫、防護劑

基面清潔 → 放樣排列 → 背面清潔 → 調砂漿 → 背面滿抹 → 由下往上貼 → 調整 → 清溢漿 → 勾縫 → 養護 → 清潔防護
