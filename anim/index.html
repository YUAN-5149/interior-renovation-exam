3D 工法動畫

術科常考的施工順序與注意事項：施工順序一步一步看構造怎麼疊上去；注意事項逐項標出位置與正確做法。都可以轉角度，每一項附考點。

施工順序 步驟題

🪵

高架木地板施工順序

10 步驟・角材骨架、固定筋、夾板、面板

管線 → 基準線 → 四周角材 → PE 布 → 主支架 → 固定筋 → 副支架 → 夾板 → 面板 → 收邊
🧱

石膏板輕隔間施工順序

10 步驟・槽鐵、立柱、開口補強、封板、批土

放樣 → 上下槽鐵 → 立柱 → 開口補強 → 管線 → 單面封板 → 隔音材 → 另一面封板 → 接縫處理 → 收邊
🏠

木作企口天花板施工順序

10 步驟・角材吊筋、格架、起拱、企口板暗釘

放樣 → 周邊角材 → 吊筋 → 骨架 → 校正起拱 → 開口補強 → 鋪企口板 → 接頭錯開 → 收邊 → 表面處理
🔲

輕鋼架天花板施工順序

9 步驟・L 型收邊條、吊筋、主架副架、礦纖板

放樣 → L 型收邊條 → 吊筋 → 主架 → 副架 → 校正水平方正 → 設備開口補強 → 放礦纖板 → 清潔檢查
🚪

造型木作壁板施工順序

11 步驟・機電移位、角材骨架、底板、面材、開孔

放樣 → 機電配合 → 基面檢查 → 立角材 → 線路測試 → 封底板 → 貼面材 → 開孔 → 線板收邊 → 塗裝 → 面板復原與通電測試
🔳

牆面磁磚硬底工法施工順序

11 步驟・純水泥漿、灰誌打底、鋸齒鏝刀、定位片、填縫

基面處理 → 純水泥漿 → 灰誌打底 → 養護 → 分割放樣 → 塗黏著劑 → 由下往上鋪貼 → 清溢漿 → 養護 → 填縫 → 清潔保護
🚿

浴廁壁面防水粉刷施工順序

9 步驟・管線止水、牆角圓角、兩層防水砂漿、彈泥、試水

基面處理 → 管線處理 → 牆角圓角 → 純水泥漿 → 第一層刮毛 → 第二層鏝平 → 彈性防水塗膜 → 養護 → 試水
🪨

牆面抿石子施工順序

10 步驟・塑膠壓條、石粒漿、海綿擦洗、凡立水

基面檢查 → 放樣 → 固定壓條 → 黏結層 → 拌合石粒漿 → 抹平壓實 → 海綿擦洗 → 清洗修整 → 養護 → 凡立水
🧱

牆面文化石軟底施工順序

11 步驟・背面滿抹、先貼轉角石、勾縫、防護劑

基面清潔 → 放樣排列 → 背面清潔 → 調砂漿 → 背面滿抹 → 由下往上貼 → 調整 → 清溢漿 → 勾縫 → 養護 → 清潔防護
🟦

牆面馬賽克舖貼施工順序

11 步驟・表貼紙、斜向抹縫、伸縮縫 PE 棒與彈性填縫

基面檢查 → 分割放樣 → 調益膠泥 → 鋸齒鏝刀 → 整張鋪貼 → 對齊校正 → 撕紙修正 → 清溢漿養護 → 抹縫 → 伸縮縫 → 清洗保護
🩹

輕隔間接縫批土施工順序

8 步驟・接縫紙帶、三道批土逐道加寬、羽化、護角條

檢查 → 第一道貼紙帶 → 點補螺絲孔 → 第二道 → 第三道羽化 → 研磨 → 陽角陰角 → 完成檢查
🗄️

櫥櫃西德鉸鍊安裝程序

9 步驟・杯孔放樣、Ø35 杯孔、座板、三向調整

確認型式 → 決定數量 → 放樣 → 鑽杯孔 → 鎖鉸鍊杯 → 鎖座板 → 掛門 → 三向調整 → 開合測試
📜

舊壁紙拆除流程

6 步驟・斷電拆面板、乾撕、劃痕、浸潤、刮除、封底

斷電保護 → 試撕乾撕 → 劃痕 → 浸潤 → 由下往上刮除 → 清洗修補封底
🧱

砌磚砌築步驟

8 步驟・拌漿到清潔（術科填空題）

拌漿 → 撥漿 → 刮漿 → 砌頭 → 擠漿 → 刮除溢漿 → 勾縫 → 清潔
🖌️

油漆塗裝前底材處理

7 步驟・木作與泥作的含水率、清潔、補土、抗鹼封底

含水率 → 清潔 → 節疤封閉 → 補土 → 研磨 → 抗鹼封底 → 遮蔽保護
🚪

防火金屬門框施工要點

8 項注意事項・依施工順序呈現

認證整組 → 錨定校正 → 灌漿防火填縫 → 門扇間隙 → 門弓器 → 不加門止 → 防火五金 → 標示
🪵

高架實木地板施工程序

9 步驟・墊木塊調高度、底板留縫、牆邊伸縮縫（114 年術科）

放樣 → PE 布 → 角材墊木塊 → 橫撐 → 底板 → 實木地板 → 接頭錯開 → 踢腳板 → 表面處理
⬜

輕鋼架暗架天花板施工順序

10 步驟・全牙螺桿、C 型主骨、暗架副骨、自攻螺絲封板

放樣 → L 型收邊條 → 吊筋 → 主骨 → 副骨 → 校正 → 開口補強 → 封板 → 批土 → 塗裝
🛁

浴室地坪磁磚軟底工法

10 步驟・防水試水、洩水坡度、乾拌水泥砂、土膏水

清潔 → 防水試水 → 放樣坡度 → 乾拌砂 → 刮平 → 土膏水 → 鋪磚 → 調整 → 養護 → 填縫
🧱

牆面水泥砂漿粉刷施工順序

9 步驟・灰誌標筋、1:3 打底、1:2 粉光、鐵鏝壓光

基面濕潤 → 純水泥漿 → 灰誌標筋 → 打底 → 刮平搓平 → 養護 → 粉光 → 壓光 → 養護
💠

嵌銅條磨石子施工順序

10 步驟・粉刷打底 → 裝銅條 → 粉刷上度 → 磨光（115 年學科）

清潔 → 打底 → 放樣 → 裝銅條 → 水泥漿 → 石粒漿上度 → 養護 → 粗磨 → 補漿細磨 → 光磨打蠟
🖌️

牆面油漆塗裝施工順序

8 步驟・補土 → 砂磨 → 底漆 → 面漆（107 年學科）

清潔遮蔽 → 補土 → 砂磨 → 底漆 → 二次補土 → 面漆一 → 面漆二 → 檢查
📜

壁紙張貼施工順序

10 步驟・封底劑、鉛垂線、悶膠、由中向外刮

底材檢查 → 批土 → 封底 → 鉛垂線 → 裁紙悶膠 → 第一幅 → 刮氣泡 → 對花對縫 → 切邊 → 擦膠檢查
🟦

滿鋪地毯施工順序

10 步驟・倒刺條、底墊、接縫、張緊器、修邊

清潔 → 放樣 → 倒刺條 → 底墊 → 裁切 → 接縫 → 張緊 → 修邊 → 收邊條 → 清潔
🟫

塑膠地磚鋪貼施工順序

10 步驟・整平、中心十字線、齒刀塗膠、晾膠、壓輥

地坪檢查 → 整平 → 清潔 → 十字放樣 → 塗膠 → 晾膠 → 中心往外貼 → 壓輥 → 修邊踢腳 → 清潔
🪟

鋁門窗安裝施工順序

放樣 → 就位木楔 → 校正 → 固定片 → 塞水路 → 養護 → 收邊 → 矽利康 → 窗扇 → 試水
🔲

強化玻璃隔間施工順序

放樣 → 天地槽 → 底墊塊 → 吊入玻璃 → 校正 → 對接打膠 → 槽內固定 → 防撞標示 → 清潔

窗簾安裝施工順序

丈量 → 補強位置 → 放樣 → 固定座 → 軌道 → 滑輪 → 掛簾 → 調整 → 開合測試
